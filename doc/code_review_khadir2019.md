# 当前实现审查与修正记录

本文件替代旧审查报告。旧报告描述了更早的代码，包含过时结论及相互矛盾的
傅里叶约定；不应继续据其错误清单重复修改算法。完整使用约定见项目 README。

## 保留的正确实现

- 保留 `sx`、`sy`。`s=(ky,-kx,0)/k_parallel` 是论文附录 B 的旋转轴 `u`，
  与论文的 s 偏振反向；并非变量或旋转方向错误。
- Rodrigues 分量展开式正确。倒立实像对应物方与像方极角相加；现在直接用
  附录 B 的单位波矢点乘与叉乘求正余弦，避免反三角函数中间量。
- 修正前代码的 `theta_img` 已使用 `kx/m, ky/m` 及 `n_img`，`theta_obj`
  已使用物方波矢及 `n_obj`；不存在旧报告声称的两项互换。
- 修正前代码已经使用 `jnp.fft.ifft2`，也已包含
  `dkx * dky * nx * ny`。旧报告中“API 不存在”和“缺少
  `(2*pi)**2 * nx * ny`”的判断不适用于该版本。

## 本次修正

1. **光轴除零**：旋转轴分母在零频点用 1 占位，得到 `sx=sy=0`；角度为零，
   原展开式返回原场。
2. **孔径外 NaN**：在求角度、开方和幅度比前屏蔽孔径外波矢与输入角谱。
   不依赖最后乘零去消除 NaN，不把倏逝波伪装成传播波。
3. **倒立与积分**：在中心化、递增的物方波矢网格上使用 `fft2` 的负指数核；
   物理幅度为 `-sqrt(kz_obj/kz_img)/m`，积分权重为 `dkx*dky`。
   不再使用原来抵消 IFFT 归一化的 `nx*ny`。
4. **网格与数组契约**：统一为中心化 `(3, ny, nx)`，形状从输入读取，明确像面
   间距、物方频率网格、单位、坐标原点及连续角谱归一化。
5. **参考面与离焦**：输入定义在物体外的 `z_field`，物方前焦面为 `z_focus`。
   使用 `exp(1j*(kz_obj*(z_focus-z_field)+kz_img*z_image))`，保留完整相位。
   焦面可置于散射体内；此换算指均匀背景中出射波的外推，不求解物体内部场。
6. **最小结构调整**：核心拆为网格、旋转、重聚焦三个模块，补公共导出和可安装的
   `src` 包配置，示例替代模板入口。
7. **界面偶极子**：新增 `dipole.py`，按 Eq. 14–16 实现单界面透射，包含源侧
   倏逝波、临界角有限极限，以及电偶极 Mie 极化率。用等折射率极限验证 Fig. 3。

## 旧报告中的其他错误与范围澄清

- `fftshift` 和 `ifftshift` 在偶数长度时相同，在奇数长度时不同；旧报告写反。
- “角度相加必然不能用 IFFT”不是一般定理。若积分变量改为像方波矢，并正确
  重采样角谱，IFFT 可以自洽。本实现固定物方网格，因此采用 FFT。
- 无 shift 不必然错误；全程使用 FFT 顺序也可以自洽。本实现明确采用中心化
  输入输出，因而只在变换边界 shift，并指定空间轴。
- Eq. 3 与完整旋转矩阵仅对横向输入等价；不应以 Eq. 3 悄悄消除错误输入的
  纵向分量。
- 偶极子和界面不属于通用重聚焦算子的输入要求；现在作为独立场源和物理验证
  实现，不将其参数混入 `refocus_field`。
- 双精度用于参考验证；库不会在导入时修改全局精度，不把单精度本身判为算法错误。

## 验证

`tests/test_refocus.py` 使用 NumPy 构造独立的论文 s/p 基和直接积分，测试：

1. 轴上平面波的有限性、幅度和整体相位。
2. Rodrigues 与 Eq. 3 一致，输出满足横波性并保持旋转前后的范数。
3. 小网格直接积分与 FFT 的完整复电场一致，包括奇偶和非方形尺寸。
4. 物方平移对应像方反向放大平移。
5. 正负像侧离焦相位、孔径边缘、孔径外倏逝采样点与全零输入。
6. 改变出射场采样面后相机复电场不变；整体移动坐标原点后不变。
7. 通过直接积分合成的实空间场转换回连续角谱，核对归一化和奇偶网格。

`tests/test_dipole.py` 验证界面透射、源侧临界角和倏逝波、均匀介质极限，以及
Fig. 3 的七组强度/OPD 曲线。后者有独立数值参考和论文理论曲线的图形参考，
具体来源、材料插值假设和容差见 `tests/data/README.md`。

运行：

```bash
JAX_PLATFORMS=cpu JAX_ENABLE_X64=true uv run python -m unittest discover -s tests -v
```

该验证针对理想显微镜和单界面的给定偶极子；不代表已验证自动微分、
多层反射、偶极矩自洽反馈或实验显微镜的像差与透射率。
